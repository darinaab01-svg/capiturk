# Capitürk в Expo Go

Открой эту страницу на компьютере. На iPhone установи **Expo Go** из App Store, открой обычную Камеру и наведи её на QR:

![Открыть Capitürk в Expo Go](./qr.png)

В Expo Go войди в тот же аккаунт, что и на компьютере: **darinaab01**.

**Адрес:** `exp://xqdfll0-darinaab01-8081.exp.direct`

Ссылка проверена 30 сентября 2026 года. Это временный туннель к работающему серверу на компьютере. **Компьютер должен оставаться включённым, с интернетом и запущенным Expo.** GitHub хранит исходники и QR, но не запускает приложение. После перезапуска туннеля адрес может измениться — старый QR тогда нужно заменить.

## Что можно попробовать

- Пять уроков первого модуля и итоговый разговор: 130 шагов.
- Турецкая озвучка слов, примеров, фраз и реплик диалогов.
- Выбор ответа, аудирование, сборка фразы, пропуски, направления, персональная история.
- Запись голоса с разрешением на микрофон и прослушивание своей записи.
- 14 прозрачных поз Капи, мягкие переходы, пульсация озвучки, волна записи и конфетти.
- Обновлённые главная, маршрут курса и карточка слова с медленной озвучкой.
- Поиск в словаре, фильтры повторения и сохранённые отметки «Знаю».
- Шесть мягких звуков взаимодействия, тактильный отклик и поддержка Reduce Motion.
- Сохранение прогресса, имени, города и настроек на устройстве.

**Разговорные упражнения здесь — самостоятельная практика. Автоматического распознавания и оценки речи нет.** Для этого служит отдельный [SwiftUI-проект](../README.md) в корне репозитория. Expo-версия использует нативные компоненты React Native; браузер и WebView не используются.

## Запустить самостоятельно

Нужны Node.js 22.13+ (проверено с Node 24) и npm.

```sh
git clone https://github.com/darinaab01-svg/capiturk.git
cd capiturk/expo
npm ci
npx expo login
npm start -- --tunnel
```

Сканируй **свежий QR из терминала**. В Expo Go и Expo CLI нужен один аккаунт. Expo Go на iPhone должен поддерживать SDK 57. При сообщении о несовместимости обнови Expo Go в App Store.

Если звук не слышно, проверь громкость и беззвучный режим iPhone. Для записи разреши микрофон для Expo Go. Запись сохраняется локально во временном кэше Expo Go; приложение не отправляет её на сервер. iOS может очистить кэш. Это не архив голосовых записей.

## Проверки

```sh
npm run typecheck
node node_modules/expo/bin/cli install --check
node node_modules/expo/bin/cli export --platform ios
node tests/content.cjs
node tests/tunnel-dns.cjs
```

Экспорт JavaScript-пакета для iOS и проверка типов выполнены на Windows. Туннель и выдача iOS-пакета проверены по HTTP. Реальные динамик, микрофон, вибрация и внешний вид на физическом iPhone требуют проверки на устройстве. Это не сборка IPA через Xcode.

Новые изображения и полные промпты: [ASSETS.md](./ASSETS.md). Все 14 WebP входят в пакет, общий размер около 1,64 МБ. При первом открытии Expo Go загружает пакет и ресурсы с компьютера; это не отдельная установленная офлайн-сборка.

При недоступности ngrok можно использовать новый туннель Expo (экспериментальный): перед `npm start -- --tunnel` в PowerShell выполни `$env:EXPO_UNSTABLE_TUNNEL_V2="1"`. Текущий QR использует обычный ngrok-туннель. [Документация Expo](https://expo.dev/changelog/sdk-58-beta#a-faster-more-reliable-expo-cli-tunnel).
