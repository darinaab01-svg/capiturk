# Capitürk

Мобильная браузерная версия для изучения турецкого языка. Пять уроков и итоговая беседа: 32 активных слова, 15 групп фраз, 130 шагов.

Откройте сайт в Safari на iPhone. Через меню «Поделиться» его можно добавить на экран «Домой».

Прогресс хранится в браузере. Озвучка использует турецкий голос устройства; запись микрофона остаётся на устройстве. Текстовая замена аудирования позволяет посмотреть урок, но не засчитывает прослушивание. Автоматической оценки произношения нет. Для загрузки нужен интернет.

Это веб-превью; нативный проект iOS собирается отдельно через Xcode.
